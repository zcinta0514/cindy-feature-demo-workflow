## 范围

- 每个案例取**最新被认可的一代**，中英文各一条；历史版本（含被新版取代的 v1/v2）未上传，避免用带缺陷的旧版冒充当前水平。
- 不含无声母版（silent master）、1080p 派生预览、返修中间轨和静态联系表。
- 早期案例是 16:9（3840×2160）；2026-11-06 起默认 4:3（3840×2880）。本表按实际文件标注，未修改旧片。
- 累计 19 条、3.37 GB。单个文件均小于 GitHub Release 2 GB 上限。

## 这些片子不等于“任意新功能可一键出片”

每条片子都是按各自案例单独适配组件宿主、写时间线并逐片质检的。成片只证明这条流程的产出形态和验收标准，不构成对新功能免检的承诺。新功能仍需按 [references/workflow.md](../references/workflow.md) 核对版本、补齐组件、逐片验收。
